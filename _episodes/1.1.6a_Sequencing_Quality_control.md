## Read Quality Control (QC)
 
Quality control of long-read sequencing data includes several steps:

(0. **Demultiplexing**: assigning each read to the correct sample based on its barcode. Strictly speaking this is not quality control, but this step is sometimes performed by tools that also do QC.)
1. Removing **barcodes**: i.e. oligonucleotides that were artificially added to identify sequences from a particular sample);
2. Removing **sequencing adapters and primers**: i.e. oligonucleotides that were artificially added to facilitate the sequencing process;
3. Trimming **low-quality nucleotides**: sequencing quality often drops towards the end of the reads.
4. **Read filtering**: Even after steps 1-4, entire reads might still be too low-quality, too short, or too long. In that case, entire reads will be removed.  This is the part you'll perform yourselves today.

### Interpreting NanoPlot output
This is an example of a plot you might get from NanoPlot. Looking at plots like this helps you estimate how much data you'd lose by filtering on read quality or length.
 
- The top plot shows the frequency of read lengths
- The large main plot shows how read quality changes with read length
- The right plot shows the frequency of read qualities
![example_qc_nanoplot](https://mgxlab.github.io/Viromics2026/assets/img/example_seq_quality.png)

Recall from this morning that every base call in a FASTQ file has a **Phred quality score**, Q, a measure of confidence in that call:
 
```
Q = -10 × log10(P_error)
```
 
| Phred score (Q) | Error probability | Base call accuracy |
|---|---|---|
| Q10 | 1 in 10 | 90% |
| Q20 | 1 in 100 | 99% |
| Q30 | 1 in 1,000 | 99.9% |
 
That's a **per-base** score: one per character in the quality string. NanoPlot, however, reports a single **per-read** quality score: one number summarising all of that read's per-base scores together. This is *not* a simple average of the per-base Q values. Because Q is a log scale, the per-base error probabilities are averaged first, and only then converted back into a Q score. In practice this means a read with a handful of very poor bases pulls the per-read score down more than a naive average of its Q values would suggest.

## Filtering reads with Chopper
 
Many phages naturally have [low-complexity regions](https://en.wikipedia.org/wiki/Low_complexity_regions_in_proteins) in their genomes (e.g. `ACACACACAC`). Nanopore sequencing errors are biased towards these regions, either creating them falsely or exaggerating them, which can introduce artefacts into assembled viral genomes. High-quality reads meaningfully improve assemblies, particularly for error-prone long reads.

## GC content (move to next lesson)
 
So far we've filtered on read quality and length. There's another useful signal worth checking: **GC content** — (sum of G's + C's) / (sum of all bases). There's no universally "correct" GC content; rather, it tells you something about the nucleic acid composition of your sample.
 
GC content is generally consistent along the length of a single genome. That means if you plot the GC content from reads coming from **one** phage genome in a histogram, you'd expect a **unimodal** distribution. Outlier regions within a genome (a horizontally transferred gene, an inserted prophage, a mobile genetic element) show up as reads that deviate from that peak.

## Python script used to make GC content plots
 
For your reference — this is the script the sbatch job above runs.
 
> ## Python script to make GC content plots
>
> ```python
> #!/usr/bin/python3
>
> from Bio.SeqUtils import gc_fraction
> from Bio import SeqIO
> import pandas as pd
> import numpy as np
> import gzip, sys
> import matplotlib.pyplot as plt
>
> fastq_path = sys.argv[1]
> out_path = sys.argv[2]
>
> def read_gc(path):
>     gc = {}
>     opener = gzip.open if path.endswith(".gz") else open
>     with opener(path, 'rt') as f:
>         for record in SeqIO.parse(f, "fastq"):
>             gc[record.id] = gc_fraction(record.seq) * 100
>     return gc
>
> gc = read_gc(fastq_path)
> df = pd.DataFrame([gc]).T
>
> fig, ax = plt.subplots(tight_layout=True)
> ax.hist(df, bins=150)
> ax.set_xlim(0, 100)
> ax.set_xticks(np.arange(0, 100, step=10))
> ax.set_xlabel('% GC Content', fontsize=10)
> ax.set_ylabel('Num of Reads', fontsize=10)
> fig.savefig(out_path, dpi=150)
> ```
