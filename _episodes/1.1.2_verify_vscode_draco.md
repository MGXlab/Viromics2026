During this course, you will use your laptop to connect to Draco, the high-performance computing (HPC) cluster at the University of Jena. Most analyses will run on Draco rather than on your laptop.
If you completed the [pre-course setup](https://mgxlab.github.io/Viromics2026/laptop_setup/index.html), you should already be able to connect to Draco from VS Code.

> ## Exercise 1 - prove it works
> 
> 1. Open VS Code
> 2. Connect to Draco using Remote - SSH (as you did in the pre-course setup).
> 3. Open a terminal and run:
>
>  ```bash
> hostname
> pwd
> whoami
> ```
>
>  {: .source}
{: .challenge}

`hostname` should print something like login1.cluster or login2.cluster.
`pwd` should print your home directory on Draco, something like `/home/<your_username>`.
`whoami` should print your URZ username.

## If anything doesn't work, call a TA before continuing with the other excercises.

> ## Exercise 2 - Copy scripts and folders
>
> Execute the following commands in the terminal 
>
> ```bash
> cd ~
> cp /vast/groups/VEO/shared_data/Viromics2026_workspace/setup_workspace.sbatch ./
> sbatch setup_workspace.sbatch
> ```
>
> This will submit a script to Draco to copy the necessary files for this course to your home directory. You can check whether it's still running with:
>
>  ```bash
> queue --me
> ```
>
> Once the job no longer appears in that list, it's done.
>
> Verify it completed succesfully by checking if the files are there:  
> 
> ``` bash
> cd ~/Viromics2026_workspace
> ls
> ls data/sequences
> ```
>
> You should see several folders and files, including a data folder containing a sequences subfolder, with one or more `.fastq.gz` files inside.
>
>  {: .source}
{: .challenge}

Now that your workspace actually has something in it, let's make sure the Explorer sidebar is pointed at it.

> ## Exercise 3 — Open your workspace folder
> 
> 1. Open the Explorer sidebar (folder icon, left edge of VS Code) and click Open Folder.
> 2. Add `/home/<YOUR-URZ-ID>`
> 3. Navigate to Viromics2026_workspace and confirm.
> 4. Expand data → sequences in the tree. Do the files match what `ls` showed you?
>
> The terminal and the Explorer are both just different views onto the same files on Draco.
> 
>  {: .source}
{: .challenge}
