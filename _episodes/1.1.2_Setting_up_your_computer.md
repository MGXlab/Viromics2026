## Overview

During this course, you will use your own laptop to connect to **Draco**, the high-performance computing (HPC) cluster at the University of Jena. Most of the analyses will run on Draco rather than on your laptop.

In this lesson you will set up your computer, connect to Draco through Visual Studio Code (VS Code), and run the course setup script.

## 1. Install VS Code

Download and install [Visual Studio Code](https://code.visualstudio.com/) for your operating system.


## 2. Install the Remote SSH extension

1. Open VS Code and look for the **Extensions** panel.
![example_qc_nanoplot](../assets/img/vscode-extensions_panel.png)

2. Search for **Remote - SSH** published by Microsoft:
![example_qc_nanoplot](../assets/img/vscode-extension-remote-ssh.png)

3. Install the extension.

You will use this extension throughout the course to work with files and run commands on Draco.

## 3. Access Draco

Once your access has been set up, connect to Draco from VS Code:

1. Open the Command Palette in VS Code by pressing command+shift+p (ctrl+shift+p on Windows or Linux). 

2. Select **Remote-SSH: Connect to Host...**

3. Alternatively, you can press the button in the lower left corner:
![image](https://github.com/user-attachments/assets/3db3b016-b33f-469f-ac3f-df490d1f34b8)

4. Select or enter the Draco host.
![image](https://github.com/user-attachments/assets/d8e9d52b-6695-4608-a33f-9e4a28d11a04)

5. Log in with your password when prompted.
If the connection is successful, VS Code will indicate that you are connected to a remote host (in this case login2.draco.uni-jena.de) by displaying a green background in the lower left corner:

![image](https://github.com/user-attachments/assets/8e19f0da-2cbd-4119-bc83-8c63d928d544)


As an extra check, open a terminal in VS Code and run:

```bash
hostname
```

The output should identify the Draco system rather than your laptop.

### Question
Where is this command being executed?
{: .question}

### Solution
VS Code is running on your laptop, but the terminal can be connected to Draco.
Commands entered in this terminal are therefore executed on Draco.
{: .solution}

## Submitting jobs on Draco

When you login to Draco, you are on the "login node" and this is not the best place to run any programs or heavier scripts. You **MUST** be on a "compute node" to run scripts and programs

You can either request for resources from a compute node and run programs interactively or submit a job to the job scheduler, which then sends it to a compute node to complete.

[See here for what slurm architecture looks like](https://mgxlab.github.io/Viromics2025/draco/index.html)

You can either request resources from a node for an "interactive" shell or you can submit via sbatch

To get resources - [see here](https://mgxlab.github.io/Viromics2025/sbatch/index.html#salloc)

To submit a job, you have to make a script `my_slurm_script.sh`  and then submit it as `sbatch my_slurm_script.sh` . Detailed information on creating these scripts, including descriptions can be found in the "extras" [here](https://mgxlab.github.io/Viromics2025/sbatch/index.html)

[Example script here](https://mgxlab.github.io/Viromics2025/sbatch/index.html#example-sbatch-script)




## 4. Run the course setup script

A setup script has been prepared for this course. It creates and configures the environment you will need for the practical exercises.

Follow the instructions provided for the course setup script.

You do not need to understand every command in the script. The purpose of the script is to make sure that everyone starts the course with a consistent computational environment.

### Checkpoint

After the script has finished, verify that the setup was successful using the checks provided with the script.

If something does not work, **stop here and ask a TA for help**. It is much easier to fix setup problems now than during a practical exercise.

## 5. Final setup checklist

Before continuing, make sure that:

* [ ] VS Code is installed.
* [ ] The Remote - SSH extension is installed.
* [ ] You can connect to Draco from VS Code.
* [ ] You can open a terminal connected to Draco.
* [ ] You know whether a command is running locally or on Draco.
* [ ] The course setup script completed successfully.
* [ ] The required course environment is available.

Once all of these checks are complete, you are ready to start working with the viromics data.
